T1000-E Dual-Mode

One firmware for the Seeed T1000-E that is both a BLE Companion and a Repeater — switch with a five-press of the button.

Seeed T1000-E · nRF52840 + LR1110 Companion (BLE) ↔ Repeater 5× button to switch optional Meshtastic beacon
⚠ Experimental. The dual-mode launcher is a work-in-progress add-on (it co-compiles two apps and picks one at boot). Flashing is reversible — you can return to any stock MeshCore image any time. The Meshtastic-beacon variant is verified working on-air (in Repeater mode).

What it is

Normally a T1000-E runs one role — you flash either the Companion firmware (a BLE node you drive from the phone app) or the Repeater firmware. This build contains both and chooses which to run at boot from a flag saved in the internal filesystem. A small launcher owns startup and dispatches to whichever app is selected; the two apps' identically-named classes coexist because the repeater's are renamed (MyMesh→RptMesh, UITask→RptUITask) when built with -D DUALMODE.

  • Companion mode (default): BLE companion radio — pair from the MeshCore app.
  • Repeater mode: a standard MeshCore repeater with serial CLI.

Switching modes

  1. Press the user button five times in quick succession.
  2. The device confirms with the buzzer — 2 beeps = switching to Repeater, 1 beep = switching to Companion — then reboots into the other mode.
  3. The choice persists across reboots (stored at /dualmode in flash).

The five-press count is otherwise unused by either app, so it doesn't collide with normal button actions. A button edge also wakes the device from the repeater's power-saving sleep so the press burst registers.

Using the Meshtastic beacon in dual-mode

In the + Beacon build, the beacon is active only while the device is in Repeater mode. Because the T1000-E has no screen, configure it from the repeater's serial console (115200 baud) with the mtbeacon commands — mtbeacon on, mtbeacon interval 5, mtbeacon send, etc. Full command reference is on the beacon page. Settings persist independently of the dual-mode flag.

Note: the on-screen < Repeater +Beacon > splash and live status line don't appear here — there's no display on the T1000-E, and the UI is disabled in dual-mode regardless. The beacon itself runs normally.
